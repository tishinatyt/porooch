## Импорт и публикация

Новый SQL: [../sql/event-source-scaling.sql](../sql/event-source-scaling.sql), точная копия миграции `20261116130000_event_source_scaling.sql`. Применять вручную после существующих миграций ingest. SQL добавляет атомарный импорт с защитой от дублей URL, переключение автопубликации, пакетную запись и RPC списка городов. Чужие таблицы не затронуты. К базе при разработке не подключались; выполнение SQL и реальные права RPC требуют проверки после ручного применения.

Вставить JSON, выбрать общее согласие на афиши, проверить таблицу, подтвердить. Существующие URL, повторные строки, хвостовой `/` и рекламные параметры учитываются при пропуске дублей. Импортированные источники всегда имеют `auto_publish=false`. Автопубликация включается отдельно в редакторе, кнопкой строки или для выбранных источников.

Сборщик и SQL проверяют будущую дату, название от 3 символов, место/адрес, отсутствие дубля и отмены/переноса. Не прошедшие проверки записи остаются pending; прошедшие события по существующему правилу становятся expired. Неразбираемые даты и пустые названия отбрасываются парсером. Отклонённые модератором неизменённые записи не публикуются повторно. Включение флага действует при следующем сборе, а не массово меняет очередь сразу.

Все 21 города уже имели точные центры в приложении; они сохранены, радиус работает от этих центров. Дополнительные города добавляются из включённых источников с опубликованными будущими событиями. Для неизвестного города используются координаты опубликованных площадок; при отсутствии координат доступна лента с пояснением вместо неверной карты. Фильтр города передаётся в публичную ленту и карту. До применения SQL остаётся прежний статический список городов.

## Ограничение нагрузки и проверка

45 секунд на источник, прерываемые HTTP-запросы, пакет до 100 событий, продолжение после ошибок. Факты всех источников сохраняются до необязательного геокодирования. Общий бюджет 150 минут внутри существующего workflow на 180 минут. Кеш площадок сохранён; при исчерпании бюджета координаты можно дополнить backfill. Итоговый JSON в журнале: sources, processed, skipped, events, changed, failed, geocoded, deferred, elapsed_ms. Ошибки и незавершённый бюджет дают ненулевой код выхода после обработки остальных источников.

Локальные тесты покрывают импорт и превью, дедупликацию URL, условия автопубликации, центры/фильтрацию городов, 105 источников, тайм-аут и продолжение после ошибки с подменой сети. Реальный полный сбор 107 источников с Supabase не запускался по ограничению задачи. Новые GitHub Secrets не нужны.
