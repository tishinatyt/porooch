# Гостевой экран и завершение регистрации — 2026-11-15

| Было | Стало |
| --- | --- |
| Посыл про создание событий и билеты повторялся в hero и OrganizerSection; три карточки были также под лентами | Посыл один раз в гостевом hero, с кнопками «Знайти подію» / «Створити подію». OrganizerSection, оба подключения и неиспользуемые стили удалены |
| Плашка HomeScreen повторяла полный посыл про билеты | Компактная плашка сохранена: «Організовуєш події? Запроси свою компанію.» и кнопка создания. Гостевой hero и авторизованная лента одновременно не отображаются |
| Завершение онбординга на `/create` возвращало на форму создания | Новый/незавершённый профиль после регистрации всегда открывает `/` — ленту. Это относится также к регистрации с event link |
| Возврат для завершения регистрации и существующего пользователя использовал одинаковую цель | Существующий пользователь с готовым профилем пропускает onboarding и сохраняет OAuth-возврат на `/create`; другие входы используют свой текущий допустимый pathname |

Причина: `finishOnboarding` вызывал `navigate(eventReturnPath(pathname))`. Теперь завершение создания профиля вызывает `navigate('/', { replace: true })`. OAuth-возврат остаётся независимым; сохранённого return-параметра нет, новый не добавлялся. Query/hash исключены из OAuth URL. Повторный вход с главной не возвращает на прежний `/create`.

Сохранённая кнопка Google-входа использует собственный класс `onboarding-signin-action`, поэтому стили удалённого OrganizerSection больше не нужны. Обновлены тесты signup/повторного входа/DOM гостя и ленты. В offline QA test harness дополнительно исправлена обработка CRLF после Windows checkout.
