# Главная: порядок лент и создание — 2026-11-15

| Было | Стало |
| --- | --- |
| Плашка «Організовуєш події?» под хедером, отдельная desktop-кнопка в хедере и пункты «Додати» | Плашка и дублирующая кнопка хедера удалены. Один видимый вход: «Створити» в BottomNav на мобильном, в AppSidebar на десктопе. Даже пустые ленты не добавляют другой create CTA |
| Знакомства первыми, афиша второй | На мобильном сверху «Афіша», ниже «Знайомства»; на десктопе афиша слева (60%), знакомства справа (40%) с независимой вертикальной прокруткой. Заголовки сохранены |
| Категории внизу афиши и отдельный набор на карте | Единая горизонтальная строка категорий сразу под шапкой. В режиме лент фильтрует только афишу, личные события не меняются; в режиме карты сохраняет фильтрацию карты |
| Афиша раскрывалась кнопкой, знакомства рендерились целиком | Обе ленты раскрывают по 10 уже полученных событий при достижении конца: горизонтально на мобильном, вертикально на desktop. Кнопки «Показати більше» оставлены как fallback; повторные scroll events не дублируют порцию |
| overflow-x:hidden мешал мобильному sticky | Корневые контейнеры используют overflow-x:clip, мобильная шапка остаётся сверху при прокрутке. Desktop сохраняет ограниченную высоту и отдельный scroll обеих колонок |

Пагинация независимая. Смена категории сбрасывает только афишу, смена поиска/радиуса/города сбрасывает обе порции. При смене фильтра соответствующий carousel получает новый ключ и начинает с начала. Это порционное отображение существующего результата discovery, без новых API или миграций.
