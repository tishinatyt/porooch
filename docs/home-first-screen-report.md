## После изменений

### LandingPage — гости

- Главный заголовок сохранён дословно: «Poruch — миттєві зустрічі зі своїми!».
- На первом экране добавлена заметная вторая линия: «Створюй свої події та продавай на них квитки разом з Poruch.fun».
- Вводный текст: «Знаходь події та свою компанію поруч — за інтересами, віком і відстанню.».
- Равноправные CTA: «Знайти подію» и «Створити подію» — одинаковые высота, ширина, цвет и типографический вес.
- «Знайти подію» вызывает прежний onStart. «Створити подію» — Link на `/create`; существующая защита показывает вход и сохраняет возврат к форме после OAuth/onboarding.
- Метка над текстом: «Події · люди · твоє місто».
- Под кнопками: «Твоя ідея. Твої люди. Квитки — незабаром.» — статус будущей продажи билетов остаётся понятным.
- OrganizerSection с прежними тремя карточками и бейджем «Незабаром» перенесён непосредственно под hero. На мобильном фото скрыто, чтобы обе линии и оба CTA были над сгибом; на desktop фото сохранено.

### HomeScreen — залогиненные

Перед статусами и лентами добавлена обычная плашка в потоке страницы:

Точный текст: «Організовуєш події? Створюй свої події та продавай на них квитки разом з Poruch.fun».

Кнопка «Створити подію» ведёт на `/create`. Плашка использует петроль #0F4C4C, янтарь #E8A33D, Fraunces и пунктирный разделитель билета. Мобильная высота — 62px. Она занимает место над лентой и не накладывается на неё. Существующий OrganizerSection внизу сохранён, фиксированная desktop-компоновка лент не изменена.

## Проверки

- `npm test`: 24/24. Сохраняются проверки гостевого перехода на вход, OAuth allowlist и возврата к `/create` после onboarding.
- `npm run build`: TypeScript, Vite и PWA успешно.
- `git diff --check`: успешно.
- Реальный headless Chrome: 360×640, 360×800, 1440×900, гостевая и авторизованная главная. Auth и Supabase замоканы на уровне браузерных модулей, live OAuth и база не используются. Все остальные UI-компоненты и CSS — настоящие, из Vite.
- На 360×640: заголовок заканчивается около 169px, второй посыл — около 274px, кнопки — около 389px, весь hero — около 435px. Оба CTA имеют высоту 48px. На 360×800 кнопки заканчиваются около 457px. На desktop — около 527px. Горизонтального переполнения нет.
- На мобильном HomeScreen плашка занимает 62px (95–157px); лента начинается ниже, около 267px. Desktop-плашка также не перекрывает ленты.
- Браузерная проверка сверяет точные украинские тексты, обе кнопки и переходы, метатеги и их длину, порядок секций, высоту плашки и отсутствие переполнения. Для кнопок допускается округление ширины CSS grid менее 0.5px.
- Визуально просмотрены мобильный и desktop-скриншоты. В процессе устранено искажение украинского текста при передаче через PowerShell; итоговые тексты проверены напрямую в DOM.

Воспроизводимая проверка без установки дополнительных библиотек: запустить `npm run dev -- --host 127.0.0.1`, затем `node scripts/check-home-viewport.mjs`. Требуется локальный Chrome (или CHROME_PATH). Скриншоты и metrics.json сохраняются в игнорируемом `dist/home-qa/`; production-сборка очищает dist, поэтому для сохранения снимков проверку запускают после сборки.
