## Откуда «Тестова подія»

Источник — `src/components/home/demoEvents.ts`: функция `getCityDemoEvents` создаёт два JavaScript-объекта на город, с ID `demo-city-<city>-personal/public`, названиями «Кава та знайомство · …» / «Відкрита прогулянка містом · …» и `isDemo: true`. HomeScreen раньше безусловно добавлял их к результатам discovery, даже если реальные события уже были. HomeEventCards и DiscoveryMap выводят бейдж именно по `isDemo`.

Теперь примеры выключены по умолчанию в обеих лентах, на карте и на прямых demo detail links. Для разработки можно поставить в `.env.local`:

```dotenv
VITE_SHOW_DEMO_EVENTS=true
```

Опция работает **только при Vite DEV=true**. В production она не включает примеры, даже если переменная случайно задана в deploy environment. Настройка описана в `.env.example`. Генератор примеров сохранён для разработки и тестов; пустая реальная выдача теперь показывает честное пустое состояние, а не подставные события.

SQL `docs/sql/test-events.sql` не создавался: указанные бейджи и названия происходят из кодовых fixtures, а не из запроса к базе. Записи в БД не проверялись и не изменялись; подключения запрещены условиями задачи.
